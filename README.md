# Bifaces Database Bulk Downloader

This repository contains a simple Python script designed to download all metadata and associated images from the [Lower Palaeolithic Bifaces Database](https://archaeologydataservice.ac.uk/archives/view/bifaces/index.cfm), hosted by the Archaeology Data Service (ADS).

## 📚 Citation

If you use this data, please cite the original source:

**Lower Palaeolithic technology, raw material and population ecology (bifaces)**  
*Gilbert Marshall, David Dupplaw, Derek Roe, Clive Gamble (2002)*  
DOI: [10.5284/1000354](https://doi.org/10.5284/1000354)

## 💡 Why Bulk Download?

While the ADS plays a vital role in archiving and preserving archaeological data, access to this particular dataset is currently limited to individual record viewing through a web interface. This can pose challenges for researchers who wish to:

- Work offline
- Perform large-scale or statistical analyses
- Integrate the data into broader archaeological research pipelines

This script enables users to bulk download all available records and images, making the dataset more accessible for analytical workflows.

At the same time, offers the downloaded data as a csv file, making easier its use for further analysis.
